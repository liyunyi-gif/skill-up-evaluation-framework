# skill-up 精修课（完整教学方案）

> 我是你的项目教学老师。这套课程把 skill-up 从「听说过」带到「能在面试里讲透、能落地实战」。
> 面向：**Java 后端 / 全栈工程师**，目标 = 改简历 + 面试 + 真实能用。
> 路径：`dev-doc/full/`（与 [`dev-doc/deep/`](../deep/README.md) 源码深挖并列；[`/doc`](../../doc/README.md) 是简历向总览）。

## 这门课怎么来的

你已经有了三套材料：
- [`/doc`](../../doc/README.md) —— 简历向总览（架构/流程/技术点/简历素材/技术栈）
- [`dev-doc/deep`](../deep/README.md) —— 8 大模块源码逐行深挖
- 本课程 `dev-doc/full` —— **把它们组织成一条「能学会」的路径**，带练习、检查点、实战和面试冲刺

`/doc` 回答「是什么」，`deep/` 回答「代码怎么写」，**本课回答「怎么学会、怎么讲出来、怎么用上」**。

## 学习路径图

```
L01 建立认知      ── 心智模型（是什么/不是什么/声明式）
   │
L02 动手跑通      ── 体感（装、写、跑、看报告）   ← 第一次成就感
   │
L03 核心流程      ── 主线（run 时序 + case 7 步）  ← 面试脊椎
   │
   ├─ L04 评测打分    ── Judge 三策略（核心子系统）
   ├─ L05 引擎适配配置 ── 多引擎 + 配置（核心子系统）
   ├─ L06 跑得稳       ── 并发/重试/超时/沙箱（基础设施）
   └─ L07 输出与安全   ── 报告/A-B/安全（产出+护栏）
   │
L08 面试与实战    ── 简历 + 模拟面试 + Capstone   ← 毕业交付
```

前 3 课是「**会 + 懂主线**」（必读）；L04–L07 是「**讲深度**」（按面试重点选）；L08 是「**转化产出**」（毕业）。

## 三种节奏（按你的时间选）

- **周末速成（2 天）**：L01 → L02 → L03 → L08（面试部分）。目标：能讲、能跑、能写简历。
- **标准（1 周，每天 1.5–2 h）**：L01–L08 全过，练习都做，Capstone 选做。
- **深入（2 周）**：标准 + 每课的「深入阅读」全看（`dev-doc/deep/` 源码）+ 完成 Capstone。

## 如何用每一课

每课固定 7 段结构：
1. **学习目标** —— 学完能做什么（可自检）
2. **本课位置** —— 前置 + 在体系中的角色
3. **讲解** —— 核心内容（Java 类比、贴代码）
4. **动手练习** —— 必做（不做≈没学）
5. **检查点自测** —— 答得上才算过
6. **深入阅读** —— 指向 `/doc` 和 `dev-doc/deep`（想深挖时看）
7. **小结 + 下一课预告**

> 老师建议：**讲解 + 练习 + 自测**三件套必须走完；「深入阅读」按精力选。别只读不练。
