## 一、skill-up 项目技术栈（贴在项目条目下）

### 紧凑一行版（适合项目标题下简介）
> Go 1.25 · Cobra CLI · OpenTelemetry · 自研 YAML DSL(v1alpha1) · 多引擎 Agent 适配(Claude Code/Codex/Qoder CLI) · LLM-as-a-Judge · MCP · Runtime 沙箱(none/OpenSandbox/Docker) · GitHub Actions CI

### 分类详版（适合「项目技术栈」小节）

| 分类 | 技术 |
|------|------|
| **语言/运行时** | Go 1.25（`maps`/`slices`/`min`/`max` 新特性） |
| **CLI 框架** | `spf13/cobra` + `spf13/pflag`（子命令、flag 别名、normalize） |
| **配置体系** | `gopkg.in/yaml.v3`；自研 `v1alpha1` 声明式 schema + 分层校验器（文档级/类型枚举/runtime 特化/case 级/去重/合并） |
| **可观测性** | OpenTelemetry（OTLP gRPC/HTTP，trace + metric），linked trace topology 跨进程父子 trace |
| **并发与控制** | goroutine + channel（信号量限流）+ `sync.WaitGroup` + `context`（超时/取消传递）；指数退避重试 |
| **沙箱与隔离** | 自研 `Runtime` 抽象，三后端：none（本地进程组）/ OpenSandbox（Alibaba 远程沙箱 HTTP API）/ Docker（shell out） |
| **跨平台** | `platform.Shell` 抽象（GOOS+Family+BashPath），`shellquote` POSIX/Windows 引用，build-tag 分平台编译 |
| **Agent / LLM 工程** | LLM-as-a-Judge（裁判 Agent）、MCP（Model Context Protocol，mocked/real × stdio/http）、prompt 工程与输出容错 |
| **集成引擎** | Claude Code / Codex / Qoder CLI / 通义千问(qwen_code) + 自定义引擎(local/http 双传输) |
| **设计模式** | 策略、工厂、模板方法、适配器、函数式选项、值对象边界 |
| **安全工程** | 凭据多源解析(flag/env/credentials.yaml)+脱敏、TOCTOU 符号链接防御、SSRF(不跟随重定向)、配置侧敏感字段检测 |
| **静态嵌入** | `go:embed`（HTML 报告模板、logo、默认配置 YAML） |
| **测试** | 表驱动测试、`go test -race`、build-tag 隔离的 e2e、外部依赖全 mock 注入 |
| **工程规范** | Conventional Commits（hook 强制）、golangci-lint + revive、gosec/noctx 安全 lint |
| **构建发布** | GoReleaser（`-ldflags` 版本注入）、GitHub Actions、Docker 容器化 GitHub Action |
| **关键依赖** | `google/uuid`、`bmatcuk/doublestar`(glob)、`joho/godotenv`(.env)、`cenkalti/backoff/v5` |

## 六、通俗讲解速查（每条是啥，Java 类比）

> 给「看着一堆名词发懵」时用。精简版见第七节。

| 术语 | 大白话 | Java 类比 |
|---|---|---|
| **Go** | 项目用的语言，适合写 CLI + 高并发后端，编译出一个独立可执行文件 | 你熟的 Java，但更轻、无 JVM |
| **goroutine + channel** | 超轻量线程 + 线程安全队列（goroutine 间传消息） | 协程≈更轻的线程；channel≈`BlockingQueue` |
| **sync.WaitGroup** | 等一批任务全干完的计数器 | `CountDownLatch` |
| **context** | 贯穿调用链的「超时+取消」控制器 | `Future.cancel()`+`Thread.interrupt()` 的统一版 |
| **go:embed** | 把静态文件（HTML/配置）编译进可执行程序 | 把资源打进 jar |
| **Cobra / pflag** | Go 写命令行工具(CLI)的框架，管子命令/参数 | `Picocli` / `Spring Shell` |
| **YAML DSL** | 用一个 yaml 文件描述「测什么怎么测」 | YAML 写 Spring 配置 |
| **分层校验器** | 读配置时多步查合法性，错误尽早报 | `@Valid` + 自定义 Validator 加强版 |
| **OpenTelemetry** | 分布式追踪标准，给每次请求画调用链(trace/span) | **SkyWalking / Zipkin / Sleuth** |
| **沙箱(Runtime)** | 每个测试一个干净隔离、用完即弃的环境 | 每个测试一个干净容器 |
| **LLM-as-a-Judge** | 让一个大模型给另一个大模型的输出打分（语义级评判） | 无（AI 专属概念） |
| **MCP** | 大模型调外部工具/数据的开放协议 = 「大模型的插件标准」 | OpenAPI 之于 HTTP |
| **多引擎适配** | 同一 Skill 装进不同 Agent(Claude/Codex/Qoder) 都跑一遍 | 适配器模式 |
| **设计模式** | 策略/工厂/模板方法/适配器 | 你 Java 里那套 |
| **凭据脱敏 / TOCTOU / SSRF** | 不打明文密钥 / 防文件偷换 / 防访问内网 | 安全基本功 |
| **表驱动测试** | 一个表列多组「输入→期望」，循环跑 | JUnit `@ParameterizedTest` |
| **golangci-lint/revive/gosec** | 代码静态检查 | `Checkstyle`/`SonarQube`/`FindSecBugs` |
| **Conventional Commits** | 规范 commit 格式（`feat:`/`fix:`） | — |
| **GoReleaser** | 自动打包发布多平台二进制 | Maven 发布插件 / `jreleaser` |
| **GitHub Actions** | CI/CD | Jenkins / GitLab CI |
